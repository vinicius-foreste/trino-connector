# Trilha de Estudo (Basico)

## Sabado - Fundamentos que destravam

1. Dimensao x Metrica
2. SUM, AVG, COUNT, COUNTD
3. Filtros de worksheet x filtros de dashboard
4. Campos calculados simples
5. Formato de numero e data

Tempo sugerido: 2 blocos de 45 min

## Domingo - Aplicacao no projeto

1. Relacionamento x Join no Tableau
2. Grao dos dados e risco de duplicidade
3. Ordem de operacoes (filtro e agregacao)
4. Validacao de KPI com tabela de conferencia
5. Ajuste visual para apresentacao

Tempo sugerido: 2 blocos de 60 min

## Checklist de aprendizado minimo

1. Sei criar um campo calculado.
2. Sei aplicar filtro global no dashboard.
3. Sei validar se um total esta duplicado.
4. Sei explicar diferenca entre competencia e pagamento.
5. Sei apresentar os 4 KPIs principais.
